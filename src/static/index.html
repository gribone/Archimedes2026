Επίλυση Ασάφειας OpenStreetMap 3 Επιπέδων

Extra Point X2

Στις πυκνές εμπορικές ζώνες (π.χ. Κέντρο Αθήνας, Θεσσαλονίκη), ένα απλό χωρικό join 50m προκαλεί ψευδείς αντιστοιχίσεις (false positives). Το ForceCRM εφαρμόζει αυστηρό πρωτόκολλο 3 επιπέδων (cKDTree + Φωνητική/Λεκτική Ομοιότητα):

✅ Tier 1 — Επαληθευμένη Ταύτιση (Confirmed Match)
Απόσταση < 50m ΚΑΙ Λεκτική Ομοιότητα Επωνυμίας ≥ 75% (ή Μοναδικό POI < 15m). Εμπλουτίζει πλήρως τα σήματα κουζίνας/ωραρίου.
100% Weight
📍 Tier 2 — Χωρική Γειτνίαση Χωρίς Επωνυμία (Spatial-Only)
Απόσταση < 25m σε ανώνυμο POI εστίασης. Χρησιμοποιείται μόνο ως ένδειξη μικρο-πυκνότητας HoReCa (250m cluster).
Spatial Only
🛡️ Tier 3 — Καραντίνα Πολλαπλών POI (Quarantined Multi-POI)
Πολλαπλά POIs σε ακτίνα < 30m με ασυμφωνία επωνυμίας (< 75%). Απομονώνεται αυτόματα ώστε να μη μολύνει το σκορ ταύτισης.
0% Noise
